# CONCHA

**Collaborative screenwriting and storyboarding, built for creative teams.**

CONCHA is a purpose-built platform that combines real‑time co‑authoring, storyboarding, a Flipnote‑inspired drawing program, a 3D reference space, and in‑app voice recording – all in one place.

- **Real‑time collaboration** – write and board together, see changes instantly  
- **Built‑in drawing tools** – sketch, animate, and attach ideas directly to scripts  
- **3D world space** – block scenes in a virtual set before you draw  
- **Record dialogue** – attach scratch voicelines to script lines  
- **Plugin support** – extend CONCHA with custom tools  
- **iOS & Android** – work on any device, anywhere  
- **Sign in with** Google, GitHub, or Discord
